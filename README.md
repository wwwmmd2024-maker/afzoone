# تصویرجو — افزونه تصویر محصولات ووکامرس

جست‌وجوی تصویر از داخل صفحه محصول، انتخاب تصویر شاخص یا افزودن به گالری، همراه با رابط فارسی و سرور مستقل لایسنس PHP.

## دانلود و شروع

- **[ZIP قابل نصب (قالب فروشنده)](packages/product-image-finder-1.0.0-template.zip)**
- **[سرور مستقل تک‌فایلی PHP](license-server/server.php)** — برای دانلود فایل از دکمه Raw یا Download در گیت‌هاب استفاده کنید.
- **[راهنمای کامل فارسی راه‌اندازی](docs/setup-fa.md)**
- **[قرارداد API و اتصال فروشگاه](docs/api-fa.md)**
- **[امنیت، محدودیت‌ها و آزمون انتشار](docs/security-and-testing-fa.md)**

> **وضعیت تحویل:** سورس، سرور و قالب ZIP آماده‌اند. چون آدرس هاست لایسنس و کلید عمومی واقعی هنوز مشخص نیست، ZIP فعلی *پیکربندی‌نشده* است: نصب می‌شود اما قابلیت‌ها تا ساخت بسته فروشنده و تأیید لایسنس قفل می‌مانند. این بسته را قبل از پیکربندی و آزمون روی هاست واقعی به مشتری نفروشید.

## قابلیت‌ها

- کادر جست‌وجو در ویرایشگر کلاسیک محصولات ووکامرس؛ استفاده از نام محصول با یک دکمه.
- Wikimedia Commons بدون کلید API؛ Brave Image Search اختیاری با کلید API خود مشتری.
- پیش‌نمایش، لینک منبع، اطلاعات مجوز، ثبت در کتابخانه رسانه و تصویر شاخص/گالری.
- تأیید حقوق استفاده، ذخیره منبع و نام صاحب اثر، محدودیت حجم ۱۰ مگابایت و ابعاد ۲۴ مگاپیکسل.
- لایسنس تصادفی ۱۲۸بیتی، اتصال به یک دامنه، اعتبارسنجی سمت سرور و توکن امضاشده RSA/SHA-256.
- پنل وب فارسی برای صدور، بازیابی سفارش، مشاهده لیست، لغو و آزادسازی دامنه.
- `licenses.txt` خصوصی با قفل فایل، نوشتن اتمیک و صدور تکرارناپذیر برای هر سفارش.
- وب‌هوک HMAC با محدودیت زمانی، فقط برای آداپتور پرداخت تأییدشده؛ صدور دستی نیز ممکن است.

## پیش‌نیازها

وردپرس ۶.۴+، ووکامرس ۸.۲+، PHP ۸.۰+ همراه OpenSSL، GD یا Imagick، دسترسی HTTPS خروجی، و نصب تک‌سایته. محیط هدف برای فروش: PHP ۸.۳ یا بالاترِ پشتیبانی‌شده. سرور لایسنس به وردپرس، دیتابیس، Composer یا کتابخانه خارجی نیاز ندارد.

## ساخت نسخه فروشنده

پس از راه‌اندازی سرور، کلید **عمومی** آن را در فایلی مثل `public.pem` ذخیره کنید:

```bash
python3 tools/build.py \
  --server-url https://licenses.example.com/server.php \
  --public-key public.pem \
  --output vendor-build/product-image-finder-1.0.0.zip
```

کلید خصوصی، رمز مدیریت، وب‌هوک و `licenses.txt` نباید وارد ZIP، وردپرس مشتری یا گیت شوند.

## محدودیت‌های مهم

1. **ضدکرک صددرصدی وجود ندارد.** کد روی هاست مشتری قابل تغییر است؛ مبهم‌سازی جای کنترل سمت سرور را نمی‌گیرد. این پروژه کد خوانا و قابل ممیزی دارد، نه ادعای کد مخفی غیرقابل‌شکستن.
2. **اتصال رسمی ژاکت/راست‌چین هنوز وجود ندارد.** API وب‌هوک پروژه سفارشی است. صدور و ارسال خودکار بعد از خرید به API/وب‌هوک و مقررات واقعی بازار مربوطه وابسته است. در نبود آن، از صدور دستی استفاده کنید.
3. نتیجه جست‌وجو تضمین عکس دقیق محصول یا مجوز استفاده تجاری نیست. برای کاهش خطا، ثبت تصویر پس از انتخاب و تأیید انجام می‌شود؛ جایگزینی بی‌تأیید و دسته‌جمعی نداریم.
4. جست‌وجو و دانلود فعلی در افزونه مشتری انجام می‌شود. برای کنترل تجاری قوی‌تر، سرویس ارزشمند جست‌وجو/پردازش باید واقعاً به سرور شما منتقل شود؛ این نسخه چنین SaaSی نیست.
5. توکن کش‌شده حداکثر ۲۴ ساعت معتبر است. لغو یا انتقال دامنه می‌تواند تا همین مدت برای نسخه آفلاین اثر نکند. پس از انقضا، قطع ارتباط به معنی قفل شدن قابلیت‌هاست؛ تصاویر قبلی حذف نمی‌شوند.

## ساختار

```text
product-image-finder/   افزونه وردپرس؛ فقط این پوشه وارد ZIP مشتری می‌شود
license-server/        سرور مستقل تک‌فایلی
packages/              ZIP قالب و SHA-256
vendor-build/          خروجی خصوصی فروشنده (خارج از گیت)
tools/                 بسته‌ساز و نمونه ارسال وب‌هوک
tests/                 آزمون اجرای واقعی PHP/OpenSSL در PHP.wasm
docs/                  راهنما و چک‌لیست انتشار
```

## آزمون‌ها

```bash
npm install --prefix .tools @php-wasm/cli@3.1.58
node tests/integration.mjs
PHP_VERSION=8.0 node tests/integration.mjs
node --check product-image-finder/assets/admin.js
python3 tools/build.py
```

آزمون یکپارچه سرور و بررسی توکن با PHP/OpenSSL واقعی اجرا می‌شود؛ این جای آزمون نصب کامل وردپرس/ووکامرس یا بررسی زنده API تصویر را نمی‌گیرد. قبل از فروش، چک‌لیست راهنما را روی هاست واقعی اجرا کنید.
